## FAQ

### What is XCutors?

XCutors is a curated collection that bundles several popular Roblox executor tools (Volt, Synapse Z, Potassium, Wave) together with a universal loader called xcutorsLoader, providing a single interface to manage and switch between them.

### Is XCutors free to use?

The xcutorsLoader itself is free and open-source. Individual executors included in the collection may have their own licensing or access requirements set by their respective developers.

### Which Windows versions are supported?

XCutors is designed for Windows 10 and Windows 11 (64-bit). Older versions such as Windows 7 or 8 are not officially supported.

### Why does my anticomponent flag the loader?

Because XCutors interacts with external processes to load scripts, some anticomponent engines may flag it as a false positive. You can safely add the installation folder to your anticomponent exclusion list.

### How do I update the executors?

xcutorsLoader includes a built-in update checker. When you launch the loader, it will automatically detect and prompt you to download any available updates for the bundled executors.

### Can I use multiple executors at the same time?

It is recommended to inject only one executor per Roblox session. However, xcutorsLoader supports multi-instance setups, so you can run different executors across separate Roblox windows.

### Where can I find scripts to use?

XCutors includes a built-in script hub with a curated selection of popular community scripts. You can also load scripts from local files (.lua or .txt) or paste them directly into the editor.

### Does this work with Roblox's Hyperion anti-enhance?

Executor compatibility can vary after Roblox updates. The XCutors collection aims to include the most up-to-date versions of each executor to maintain compatibility. Always keep your executors updated via the loader.

### How do I report bugs or request features?

You can open an issue on the GitHub repository's Issues tab. Please include your Windows version, the executor you were using, and steps to reproduce the problem.
